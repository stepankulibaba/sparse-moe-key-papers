# Данные проекта

Здесь лежат сохранённые входы для расчёта.

## Что лежит в папке

| Файл | Содержимое |
| --- | --- |
| `corpus.json` | Метаданные 140 работ, их версии, ссылки и авторы |
| `scope_audit.csv` | Решения о включении статей в корпус и причины отбора |
| `bibliographies.json` | Извлечённые библиографии с адресами и хешами PDF |
| `contexts.csv` | 1909 найденных контекстов цитирования со страницами источников |
| `context_coverage.csv` | Покрытие контекстами всех 550 связей графа |
| `provenance.json` | Происхождение снимка, параметры запросов и контрольные суммы |

## Откуда взяты данные

Сначала я получил 747 уникальных записей OpenAlex. После тематического отбора и объединения версий осталось 140 работ за 2017-2025 годы. В корпус вошли статьи об архитектурах, маршрутизации и системах Sparse MoE для языковых моделей, включая мультимодальные модели с текстом.

Граф содержит 122 связи из метаданных OpenAlex и ещё 428 связей, найденных по названиям статей в библиографиях PDF. Полные исходные ответы сохранены в истории Git.

Для текстового пилота `R` я использовал 1909 контекстов. Ассистент разметил 80 контекстов, отмеченных эвристикой. После объединения повторов получилось 36 положительных пар статей.

## Ограничения

Корпус не охватывает всю область. Часть ссылок отсутствует в метаданных, а поиск названий в PDF может пропустить связь. Пустой список литературы в OpenAlex не означает, что у статьи нет ссылок.

Восемь связей противоречат порядку дат. Для `U`, `B` и Katz я исключил их, получив граф из 542 рёбер без циклов. PageRank, число прямых ссылок и дробный подсчёт используют полный граф.

Цитирование может быть фоновым упоминанием или сравнением с другой моделью. Показатель `R` рассчитан по частичной разметке ассистента, без независимой человеческой проверки. Частоты попадания в пятёрку при удалении связей показывают устойчивость к заданному сценарию потери данных.

## Как восстановить исходный набор

Компактные входы можно заново подготовить из исходного снимка в истории Git:

```powershell
py -X utf8 tools/prepare_data.py
```

Команду нужно выполнять из корня полного клона репозитория. Она перезаписывает `data/` и `settings.json`, поэтому свою разметку стоит сохранить заранее. Для обычного расчёта достаточно уже готовых файлов, в том числе в ZIP-архиве репозитория.
